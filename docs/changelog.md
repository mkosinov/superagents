# Changelog

Framework version history. The current version lives in the [README](../README.md).

- **3.14** — brainstorming skill gains an explicit **divergence phase** (user decision 2026-10-07: the skill was a convergence machine inherited from its gate origin — nothing in the pipeline widened the option space). Between clarifying questions and the 2-3 approaches: reframe the problem (2-3 alternative problem statements incl. "are we solving the right problem"), a wide idea sweep under **deferred judgment** (feasibility/YAGNI/reuse-first are parked until convergence — judging mid-sweep kills the ideas the sweep exists to surface), one deliberately unconstrained **wild card** (dies at convergence by design; its job is exposing the assumptions of the obvious approach), then converge (YAGNI fires here) to the 2-3 working approaches — survivors of the sweep, with one line each on what died. Scaling rule: full treatment for large functional blocks, one quick reframe + short sweep for small ideas. New anti-pattern: "the obvious solution wins by default". Both ports (host + container); no canon prose change (canon names the skill, does not narrate its internals).

- **3.13** — adapter seeds synced to the A/B/C canon (step 2 of the theory/adapter separation; the seeds still carried the pre-2026-09-18 model): host `design-phase` skill back-ported from memo's live skill minus memo-specific mechanics (container panel runner, host field stamping, `app:*` attribution labels, `depends-on` parsing) — gates A/B/C with the `gate` card field (`concept`/`spec`/`plan`/`blocked`; this script variant clears it explicitly — no auto-clear on status flips), scout actuality check + stale auto-close, step-0 report, fast-track, Behavioral Delta in the spec; both `github-board` skills aligned to the board etalon (statuses `Hold`…`deployed` + `Not planned`, gate values, card-on-issue-creation rule); both `brainstorming` skills are standalone explicit-only dialogues (no gate routes through them); `manager.md`/`architect.md` fallback DESIGN flow rebuilt as Step 1 scout+concept (A auto) / Step 2 spec+panel (B human) / Step 3 plan+review+worktree (C auto) with push-at-gate timing, plus the live finishing improvements back-ported: two-dispatch finish (`PR_CREATED` → card `PR (G7)` → CI watch + merge in Dispatch 2), `gate N blocked` on a failed finish, issue closed after merge if still open, `Closes #N` in the PR description only; `writing-plans` — Behavioral Delta lives in the spec, the plan does not restate it; `plan-reviewer` descriptions and the `gh_board.py` gate-marker docstring de-G2'd (twins synced).
